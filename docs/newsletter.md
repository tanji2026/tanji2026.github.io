# 簡化版碳吉筆記電子報

日常只需：預覽自動排好的電子報、寄測試信給自己、確認本週寄送。

- 使用 Asia/Taipei 時間，收錄週一 00:00 至下週一 00:00 前發布、目前仍公開且未寄過的文章；包括完整星期日。
- 不選文章、不重填標題或摘要、不另填前言。主旨固定，標題、摘要（空白時擷取內文）與封面取自文章。
- 先顯示最近完整一週尚未寄送的內容；該週沒有待寄內容時，顯示本週尚在累積的預覽。
- 提前確認也要等週一 08:00；到時間未確認仍不寄。時間已過後才確認，會在下一輪排程開始補寄（最遲約 15 分鐘）。
- 沒有文章不寄空信。按「寄測試信」不會核准正式寄送。
- 正式寄送開始前新增、修改或下架文章，會使舊核准失效；畫面顯示更新預覽，須再按一次確認。系統絕不把未看過的新內容套進已核准信件直接寄出。
- 正式寄送開始後內容快照與收件名單固定，期號持續累計、不按年度重置；補寄只針對未成功對象。
- 郵件服務無法確認是否接受時，停止自動重寄，避免重複寄送；介面顯示待核對。既有後端保留人工核對 API。
- 舊版編輯型電子報的未寄核准會暫停，須在新版自動預覽重新確認。

保留原網站、文章草稿與公開版本分離、競賽作品、媒體、分類與既有路由。沒有變更 Firestore 訪客權限，也不需重新設定寄信密碼。

信件恢復深紫底、淡紫按鈕、白色標題與明確內文色。採 email table、bgcolor 與逐段 inline 顏色，降低郵件客戶端移除容器樣式後文字變淡的問題；實際 Gmail 顯示仍請用測試信確認。

驗證：tests/newsletter.test.cjs（自動週報邊界、核准、補寄與安全測試）、tests/newsletter-admin.test.cjs（實際 JSDOM 操作）、tests/newsletter-firestore.test.cjs（固定 localhost demo 專案真實 Firestore SDK 整合）。全部使用模擬郵件，不寄真信。
